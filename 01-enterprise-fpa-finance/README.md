# Enterprise FP&A Finance — Power BI

Group financial planning and analysis for a six-entity, six-currency group: actual vs
budget vs forecast, FX translation, scenario planning, working capital and cash,
built as code end to end: SQL Server data platform → Power Query → semantic model
(TMDL) → report (PBIR).

> **Synthetic data.** Every table in this project is synthetic and portfolio-safe
> (the fictional "Northstar" group). It must never be presented as a real company's
> financial data.

![Executive Summary](Validation/evidence/listing/exec.png)

## What it answers

- How the group's **P&L** compares with **budget and forecast** — revenue, gross
  margin, operating expense, operating profit — by entity, department and account,
  with favourable/unfavourable variance.
- What the result is in the **reporting currency (AUD)** once six local ledgers are
  translated, and how much of the year-on-year change is **currency** rather than
  performance.
- What the full-year **outlook** looks like under **scenarios** (revenue, cost and
  exchange-rate drivers).
- How much is tied up in **receivables and payables**, how old it is, and how much
  **cash** each entity holds.
- How far the source data can be trusted, and what was done about it.

## Built to survive an expert's cross-check

- **One as-of date (31 Aug 2026)**, and balances computed from dates: an invoice paid
  after the as-of date was open on it, whatever its status says today.
- **Correct translation**: each ledger line at its month's average rate; AUD fixed at 1
  (the source's AUD rate was not); spot and prior-year rates kept for audit and
  constant-currency analysis.
- **Like-for-like plan comparison** down to operating profit — the budget has no
  interest, FX or tax lines, so those are never shown as a 100% variance.
- **No rescaling**: the ledger is a partial extract (payroll posts in 68% of
  department-months) and actuals sit at a fixed fraction of plan; this is measured,
  reported and labelled, never "fixed".
- **The forecast's "Scenario" column is exposed for what it is** — one random label
  per line — and real scenarios are built from explicit, labelled driver assumptions.

## Architecture

```
Data/raw/*.csv ──BULK INSERT──▶ stg (text landing)
                                  │  typed, constrained, translated
                                  ▼
                                dbo (star schema, trusted FKs, FX, FactFinancials)
                                  │  contract
                                  ▼
                                analytics.vw_*  ──Power Query──▶  semantic model (TMDL)  ──▶  report (PBIR)
```

| Layer | Holds |
|---|---|
| `stg` | One NVARCHAR landing table per CSV, so a bad value can never abort a load |
| `dbo` | Typed star schema; 39 engine-trusted foreign keys; daily and monthly FX; the translated ledger; `FactFinancials` (actual, budget and forecast at one grain, 168,782 rows); AR/AP stated as of the as-of date |
| `analytics` | 19 views — the only objects Power BI reads |
| Semantic model | 20 tables + 2 calculation groups (Actual/Budget/Forecast and period), 133 measures, dynamic RLS by entity and department — generated by `Python/02_generate_semantic_model.py` |
| Report | 8 pages behind a navigation rail, 193 visuals of 22 types, in the client's dark theme — a rotating palette where each card and each page carries its own hue — generated by `Python/04_generate_report.py` |

## Build

Requires SQL Server 2019+ (Express is enough), `sqlcmd`, Power BI Desktop, and
Python 3 with pandas, pyodbc and jsonschema.

```powershell
python Python\01_data_audit.py                                # audit the raw files
powershell -ExecutionPolicy Bypass -File SQL\run_all.ps1      # build and validate the database
python Python\02_generate_semantic_model.py                   # write the semantic model
powershell -ExecutionPolicy Bypass -File Validation\parse_tmdl.ps1
python Validation\verify_semantic_model.py                    # model vs live SQL views
python Python\04_generate_report.py                           # write the report pages
python Validation\validate_report_layout.py                   # navigation, overlap, titles
powershell -ExecutionPolicy Bypass -File Validation\open_powerbi.ps1 -Restart   # open + refresh
powershell -ExecutionPolicy Bypass -File Validation\reconcile_measures.ps1
python Validation\generate_visual_queries.py | Set-Content $env:TEMP\q.dax
powershell -ExecutionPolicy Bypass -File Validation\validate_visuals.ps1 -QueryFile $env:TEMP\q.dax
python Python\03_generate_measure_dictionary.py
```

No machine path is committed.
