# DAX Measure Dictionary - Omnichannel Marketing Attribution

Generated by `Python/03_generate_measure_dictionary.py` from `Python/model_measures.py`. **Value (all data)** is each measure at the grand total, measured in the live Power BI model by `Validation/reconcile_measures.ps1` - not typed by hand. Attributed measures use the default model (Position-Based). Money is USD at planning FX rates. The data is synthetic.

**85 measures in 9 folders.**

## 01 Model Controls

| Measure | Value (all data) | Description |
|---|---|---|
| As Of Date | 2026-08-31 | Last day of recorded marketing activity, read from ModelConfig. Anchors every figure in the report: nothing dated later is counted, except in the Post-Period measures. Never TODAY(). |
| Reporting Currency | USD | Currency of every money measure. Spend is converted at planning rates, not market rates. |
| Attribution Model Key | 4 | Model in effect: the one selected, else the configured default. Deliberately NOT a sum when several models are in scope - credit from different models describes the same revenue and must never be added. |
| Attribution Model In Use | Position-Based | Name of the attribution model the attributed measures are using - shown on the report so a reader always knows. |
| Report Context | Data as of 31 Aug 2026  |  Attribution: Position-Based  |  USD at planning FX | One line stating the basis of every figure on the page: as-of date, attribution model, currency basis. |
| Conversion Window Days | 58 | Longest observed time from lead creation to booked revenue (58 days). A lead cohort younger than this has not finished converting, so conversion trends leave it out. |

    ADDCOLUMNS (
        ALL ( DimAttributionModel[ModelKey] ),
        "@Rev",
            VAR ModelKeyRow = DimAttributionModel[ModelKey]

                    SUM ( FactAttributionCredit[AttributedRevenueUSD] ),

<details><summary><code>Campaign Index z</code></summary>

```dax
VAR KeyInUse = [Attribution Model Key]
VAR CampaignRevenue = [Attributed Revenue USD]
VAR ExpectedRevenue =
    [Spend Share %] * CALCULATE ( [Attributed Revenue USD], ALLSELECTED ( DimCampaign ) )
VAR Dispersion =
    CALCULATE (
        SELECTEDVALUE ( DimAttributionModel[CampaignDispersionUSD] ),
        REMOVEFILTERS ( DimAttributionModel ),
        DimAttributionModel[ModelKey] = KeyInUse
    )
RETURN
    IF (
        HASONEVALUE ( DimCampaign[CampaignID] ) && ExpectedRevenue > 0,
        DIVIDE ( CampaignRevenue - ExpectedRevenue, SQRT ( ExpectedRevenue * Dispersion ) )
    )
```
